# Tugas 6 — Manipulasi Data dengan Pandas

Folder ini berisi notebook praktik manipulasi data menggunakan Pandas pada dataset transaksi POS periode 2024–2025.

## File

- `Tugas Manipulasi_Data_Pandas_pos.ipynb` — notebook pengerjaan tugas manipulasi data.
- Dataset yang digunakan berada di direktori utama repository: `paket_a_transaksi_pos_2024_2025.csv`.

## Materi yang Dibahas

1. **Indexing & Selection** — memilih baris dan kolom tertentu.
2. **Operasi Aritmatika** — melakukan perhitungan pada kolom data.
3. **Filtering** — menyaring data berdasarkan kondisi.
4. **Sorting** — mengurutkan data.
5. **Grouping & Agregasi** — mengelompokkan data dan menghitung ringkasan.

## Menjalankan Notebook

Dari direktori utama repository, instal dependensi dan jalankan Jupyter:

```bash
pip install -r requirements.txt
jupyter notebook
```

Buka notebook pada folder `Tugas 6`. Notebook telah menggunakan path relatif `../paket_a_transaksi_pos_2024_2025.csv` agar dapat menemukan dataset di direktori utama.
