# Pengantar Sains Data

Repository ini berisi kumpulan tugas mata kuliah **Pengantar Sains Data** menggunakan Python, Pandas, dan Jupyter Notebook.

## Struktur Repository

```text
Pengantar-Sain-Data/
├── Tugas 5/
│   ├── Analisis_Pendapatan_POS.ipynb
│   ├── grafik_pendapatan_per_tahun.png
│   ├── hasil_pendapatan_per_tahun.csv
│   └── README.md
├── Tugas 6/
│   ├── Tugas Manipulasi_Data_Pandas_pos.ipynb
│   └── README.md
├── paket_a_transaksi_pos_2024_2025.csv
├── requirements.txt
└── README.md
```

## Daftar Tugas

### Tugas 5 — Analisis Pendapatan POS
Analisis pendapatan transaksi POS per tahun (2024–2025). Proses meliputi pemeriksaan dan pembersihan data, perhitungan pendapatan bersih, pengelompokan berdasarkan tahun, serta visualisasi hasil.

[📁 Buka folder Tugas 5](./Tugas%205/)

### Tugas 6 — Manipulasi Data dengan Pandas
Praktik manipulasi dataset transaksi POS menggunakan lima materi: Indexing & Selection, Operasi Aritmatika, Filtering, Sorting, serta Grouping & Agregasi.

[📁 Buka folder Tugas 6](./Tugas%206/)

## Dataset
Dataset utama: `paket_a_transaksi_pos_2024_2025.csv`.

Kedua notebook membaca dataset dari folder utama repository, sehingga jalankan notebook dari folder tugas masing-masing dengan path dataset relatif yang sudah disesuaikan.

## Instalasi dan Menjalankan

1. Pastikan Python 3 sudah terpasang.
2. Instal dependensi:

   ```bash
   pip install -r requirements.txt
   ```

3. Jalankan Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Buka notebook pada folder Tugas 5 atau Tugas 6.

## Dependensi
Daftar pustaka Python yang digunakan tersedia di [requirements.txt](./requirements.txt).
